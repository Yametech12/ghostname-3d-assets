# ghostname-3d-assets

3D character models (GLB) that power the bots on the Ghostname Work Dashboard.

## Models

Fourteen rigged low-poly characters in `models/`, each with 16 to 17 animation
clips (Idle, Walk, Run, SitDown, StandUp, Victory, and more), converted from
glTF to binary GLB for fast web loading.
